快速上冰

你需要：一台电脑、一个 Antarctic 账号、以及低于 30°C 的室温（高于这个温度，安装程序会先劝你开空调）。

1. 安装 antarctic

安装
$ npm install -g @antarctic/cli
$ antarctic --version
antarctic 4.5.0 (frozen build, −89.2°C)

2. 初始化你的第一片冰

~/expedition — zsh
$ antarctic login
$ antarctic cold init
✓ 已检测到环境温度：28°C（过热）
✓ 已生成 .antarcticrc（请勿提交到仓库，里面有你的体温）
✓ 已部署 6 只哈士奇（Agent）

3. 出发

~/expedition — zsh
$ antarctic mush --to 南极点
→ 预计抵达：冷静之后

恭喜，你已经完成了 Colding。接下来可以阅读 CLI 参考，或者直接去 给狗狗挑一副好背带。

CLI 参考

所有命令都以 antarctic 开头。雪橇口令与国际通用口令保持一致，方便你的哈士奇跨平台迁移。

命令作用备注
cold init初始化环境，部署雪橇队会先测量室温，过热会拒绝执行
mush --to <地点>出发前往目的地支持 --via 途经点；不支持“热带”
hike起步 / 加速与 mush 等价，更有礼貌
gee右转 
haw左转哈士奇默认偏好此命令，详见相关研究
whoa停车响应延迟取决于前方是否有雪堆
on-by --agent <名字>让某只哈士奇无视干扰继续前进常用于松鼠、雪人、另一支雪橇队
easy减速下坡必备
status查看队伍状态、冰块余额与士气士气低于 30% 时会自动建议发肉干
harness fit检查背带松紧并自动对齐参考马具尺码表
thaw解冻已禁用 违反《负责任冷缩政策》
关于 thaw：出于安全原因，antarctic thaw 在所有版本中均不可用。如果你执行了它，CLI 会回复“你确定吗？”，然后假装没听见。

冰块 API

冰块 API 是一个 REST 接口。你发送一段文字，我们返回一段冷静的文字。所有请求以冰块（Ice Tokens）计费，价格见此。

POSThttps://api.antarctic.example/v1/freeze

请求示例

request.sh
curl https://api.antarctic.example/v1/freeze \
  -H "x-api-key: $ANTARCTIC_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "cold-floe-4.5",
    "temperature": -89.2,
    "max_ice_cubes": 1024,
    "thinking": { "type": "deep_cold", "budget_ice_cubes": 4000 },
    "messages": [
      { "role": "user", "content": "我老板又改需求了，怎么办？" }
    ]
  }'

响应示例

response.json
{
  "id": "frz_01HUSKY6DOGS",
  "model": "cold-floe-4.5",
  "content": [
    { "type": "text", "text": "先喝一口冰水。然后把需求写下来，冻一晚，明天再看。" }
  ],
  "stop_reason": "calmed_down",
  "usage": {
    "input_ice_cubes": 23,
    "output_ice_cubes": 31,
    "melted_ice_cubes": 4,      // 不计费
    "cache_frozen_ice_cubes": 0
  },
  "core_temperature": -89.2
}

参数

参数类型说明
modelstringcold-floe-4.5 / cold-sleet-4.5 / cold-hail-ku-4.5
temperaturenumber默认 −89.2，可选范围 −89.2 到 −15。传入正数会返回 418。
max_ice_cubesinteger最多输出多少块冰。超出部分自动铲走。
thinkingobject开启深度冷思考。budget_ice_cubes 越大，想得越久，人越冷静。
streamboolean冰川流式输出。请注意，冰川的流速约为每年 1 米。
cache_controlobject冷藏缓存。命中后便宜 90%，因为已经冻好了。

Mush 指令协议（MCP）

Mush 指令协议是一套开放标准，用于把外部工具、数据和补给接入你的雪橇队。一个 Mush 服务器可以暴露三类东西：

  • 工具（Tools）：冰镐、冰锥、冰钓竿。哈士奇可以按需调用。
  • 资源（Resources）：地图、补给点、附近的厕所（如有）。
  • 口令（Prompts）：预设好的口令组合，例如“绕开冰裂缝”。

连接一个 Mush 服务器

~/expedition — zsh
$ antarctic mcp add icefishing --url https://mush.example/icefishing
✓ 已连接 Mush 服务器：icefishing
✓ 发现 3 个工具：drill_hole, cast_line, pretend_not_cold
$ antarctic mcp list
icefishing   3 tools   延迟 12 ms   士气 高
sausage      1 tool    延迟 0 ms    士气 极高（狗狗最喜欢的服务器）

兼容性

犬种MCP 支持说明

错误码

我们尽量让每一个错误都和成功一样冷静。

状态码名称含义与建议
400雪地不平请求格式有误。检查 JSON 里是否混进了雪花。
401没系背带缺少 API Key。我们绝不让任何请求在未系 Harness 的情况下上路。
404被雪埋了资源不存在，或者今晚的雪太大。
418我是茶壶，太热了你传入了正数 temperature。请把茶壶放进冰箱再试。
429狗累了请求过于频繁。哈士奇需要休息，请按 retry-after 头部等待，并考虑发一根肉干。
451正在融化请求内容含有过多热量（如“火锅”“桑拿”“KPI”），已被冷安全策略拦截。
500冰裂我们这边出了问题。工程师已穿上冰爪赶往现场。
503冰面维护正在浇冰，请稍候。可在状态页查看进度。
507冰柜满了你的冻存记忆已达上限。请删掉一些旧冰，或升级到 Max。

限速

限速取决于狗。具体来说，取决于你的方案配了几只狗，以及它们今天的心情。

方案每分钟请求每日冰块拉车成员
Free（Freeze）550一只柯基（会坐下休息）
Pro（Pro-tective）5005,000标准 6 犬队
Max（−80°）10,000100,000全年托管雪橇队 + 替补
企业版按冰川面积按冰川面积见企业版

收到 429 时，响应头会包含 retry-after（单位：秒）和 x-dog-mood（单位：尾巴摇动频率）。当 x-dog-mood 低于 1 Hz 时，建议今天就到这里。
